# ZOcre Framework — Official Public GitHub Organization

This repository powers the official public GitHub organization profile for **ZOcre Framework**:

https://github.com/ncore-framework-official

The rendered organization landing page is maintained in:

`profile/README.md`

## Public-only organization

`ncore-framework-official` is the exclusive namespace for newly approved official public ZOcre repositories, releases and public documentation.

Private development remains outside this organization.

This repository must never contain:

- private GDDs;
- qualification reports;
- internal build/deployment tooling;
- secrets, tokens, keys or private webhooks;
- private infrastructure details;
- unpublished proprietary source code.
